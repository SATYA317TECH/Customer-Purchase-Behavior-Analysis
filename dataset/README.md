# Dataset Information

The dataset used in this project is the **Online Retail Dataset**, which is larger than GitHub’s file size limit.

You can download the dataset from Kaggle using the link below:

🔗 https://www.kaggle.com/datasets/ulrikthygepedersen/online-retail-dataset

After downloading, extract the file and place:

online_retail.csv

inside the `dataset/` folder before running the code.
